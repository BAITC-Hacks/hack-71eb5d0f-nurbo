# Фильтр шума в событиях

Скрипт читает 8 событий из `events.json` (уровни info / warn / critical),
оставляет только `critical` и печатает одну итоговую фразу: «критичных N».

## Как запустить

```bash
python3 filter_events.py               # читает events.json
python3 filter_events.py other.json    # или другой файл
```

Нужен только Python 3.9+, зависимостей нет.

## Что получилось

```
[critical] disk 90%
[critical] payment failed
[critical] db timeout
критичных 3
```

Из 8 событий 5 — шум (4 info и 1 warn), остались 3 критичных.

## Как устроено

Обычный фильтр по полю `level` (`level == "critical"`), без агентов и LLM.

## Ограничения

- Совпадение строгое: уровень `CRITICAL` в другом регистре не попадёт в выборку.
- `warn` полностью отбрасывается; если нужно, его можно вывести отдельным счётчиком.
