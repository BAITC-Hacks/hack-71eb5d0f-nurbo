# Классификатор обращений

Маленький скрипт: читает 5 обращений из `messages.txt`, для каждого печатает
категорию (**справка / жалоба / другое**) и черновик ответа на русском.

## Как запустить

```bash
python3 classify.py            # читает messages.txt
python3 classify.py other.txt  # или другой файл
```

Нужен только Python 3.9+, зависимостей нет.

## Как устроено

Категория определяется простыми правилами по ключевым словам (словарь `RULES`
в `classify.py`). Для каждой категории есть один шаблон ответа (`REPLIES`).
Обращения без совпадений попадают в «другое».

## Что получилось

| # | Обращение | Категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi‑Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | другое |

## Ограничения и идеи

- Правила ловят только известные слова; новые формулировки уйдут в «другое».
- Ответы шаблонные — следующий шаг: вызов LLM, который подставляет детали
  из самого обращения (например, «корпус B»).
